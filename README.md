# 🌐 Social Media App

A full-stack social media platform built using the MERN stack, featuring real-time communication, user authentication, and community-based interactions.

---

## 🚀 Features

- 🔐 Secure user authentication (JWT + bcrypt)
- 👤 User profiles with avatar upload (Cloudinary)
- 📝 Create, edit, and delete posts
- 💬 Real-time messaging using Socket.io
- 👥 Community creation and management
- ❤️ Like and interact with posts
- 📱 Fully responsive UI

---

## 🛠️ Tech Stack

**Frontend:**
- React.js
- Context API
- CSS / Material UI

**Backend:**
- Node.js
- Express.js

**Database:**
- MongoDB (Mongoose)

**Other Tools:**
- Socket.io (real-time communication)
- Cloudinary (image storage)
- JWT (authentication)
- bcrypt (password hashing)

---

## 🏗️ Architecture Overview

- RESTful API-based backend
- Modular folder structure for scalability
- Client-server communication via HTTP + WebSockets
- Stateless authentication using JWT
